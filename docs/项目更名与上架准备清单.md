# 项目更名与上架准备清单

本文档列出在正式上线前需要调整的文件和内容。按优先级排列。

---

## 优先级：🔴 必须 | 🟡 建议 | 🟢 可选

---

## 1. 项目名称相关（显示名称）

### 🔴 iOS 显示名称
- **文件**: `ios/Runner/Info.plist`
- **内容**:
  ```xml
  <key>CFBundleDisplayName</key>
  <string>Coriander Player</string>  <!-- 改为新名称 -->

  <key>CFBundleName</key>
  <string>coriander_player</string>  <!-- 改为新名称 -->
  ```

### 🔴 macOS 显示名称
- **文件**: `macos/Runner/Info.plist`
- **内容**:
  ```xml
  <key>CFBundleName</key>
  <string>Coriander Player</string>  <!-- 改为新名称 -->
  ```

- **文件**: `macos/Runner/Configs/AppInfo.xcconfig`
- **内容**:
  ```properties
  PRODUCT_NAME = Coriander Player  # 改为新名称
  ```

---

## 2. Bundle Identifier（应用唯一标识）

### 🔴 macOS Bundle ID
- **文件**: `macos/Runner.xcodeproj/project.pbxproj`
- **内容**:
  ```
  PRODUCT_BUNDLE_IDENTIFIER = com.example.corianderPlayer
  ```
  ⚠️ `com.example` 是占位符，**上架 App Store 必须改成你的真实域名**，例如：`com.senyepss.corianderPlayer`

- **文件**: `macos/Runner/Configs/AppInfo.xcconfig`
- **内容**:
  ```properties
  PRODUCT_BUNDLE_IDENTIFIER = com.example.corianderPlayer
  ```

### ✅ iOS Bundle ID（已改为 senyepss）
- **文件**: `ios/Runner.xcodeproj/project.pbxproj`
- **当前值**: `com.senyepss.corianderPlayer`（已 OK）

## 3. 版权声明

### 🟡 macOS 版权声明
- **文件**: `macos/Runner/Configs/AppInfo.xcconfig`
- **当前值**:
  ```properties
  PRODUCT_COPYRIGHT = Copyright © 2025 com.example. All rights reserved.
  ```
- **建议改为**:
  ```properties
  PRODUCT_COPYRIGHT = Copyright © 2025 Your Name or Company. All rights reserved.
  ```

### 🟡 项目描述
- **文件**: `pubspec.yaml`

## 7. 彻底更名的代价（🟢 可选，大工程）

如果要将包名 `coriander_player` 彻底改为新名称，需要修改：

### 需要修改 ~100+ 个文件的 import 语句
- 搜索所有文件中的 `import 'package:coriander_player/...'`
- 替换为 `import 'package:新包名/...'`

### 需要修改的文件类型
- 所有 Dart 文件（`*.dart`）中的 import
- Rust 配置：`rust/Cargo.toml`、`rust/Cargo.lock`
- 各种配置文件中的引用

⚠️ **通常不建议做，除非要完全摆脱"coriander"品牌**。改显示名称（CFBundleDisplayName）足以满足上架需求。

---

## 8. 其他需要检查的细节

### 临时文件名前缀
- **文件**: `lib/cloud_service/cloud_audio_player.dart`
- **内容**:
  ```dart
  'coriander_meta_${DateTime.now().millisecondsSinceEpoch}'
  'coriander_metaidx_${DateTime.now().millisecondsSinceEpoch}'
  'coriander_cloud_${DateTime.now().millisecondsSinceEpoch}'
  ```
- 这是用于云音频的临时文件名，不影响显示，可以不改

### Rust 测试目录名
- **文件**: `rust/src/api/tag_reader.rs`
- **内容**:
  ```rust
  let dir = std::env::temp_dir().join("coriander_player_tests");
  let test_dir = Path::new("/tmp/coriander_webdav_test");
  ```
- 这是开发测试用的，可以不改

---

## 总结：最小改动清单

要保持项目名为 "Coriander Player" 但能上架，只需要改以下 3 处：

| 序号 | 文件 | 改动 |
|------|------|------|
| 1 | `ios/Runner/Info.plist` | `CFBundleDisplayName` → 新名称 |
| 2 | `macos/Runner/Info.plist` | `CFBundleName` → 新名称 |
| 3 | `macos/Runner/Configs/AppInfo.xcconfig` | `PRODUCT_NAME` → 新名称 + `PRODUCT_BUNDLE_IDENTIFIER` → 真实域名 |
