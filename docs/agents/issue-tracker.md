# Issue Tracker

**Tracker type:** GitHub Issues
**Repository:** marscey/coriander_player
**CLI:** `gh`

## Workflow

- Create issues with `gh issue create`
- Read issues with `gh issue view` and `gh issue list`
- Update issues with `gh issue edit` and `gh issue comment`
- Close issues with `gh issue close`

## PRs as a triage surface

External PRs are **not** a triage surface. Only GitHub Issues are processed by the triage skill. Collaborators' in-flight PRs are left alone.
